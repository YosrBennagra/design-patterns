# Creational Patterns

Creational patterns control how and where objects come into existence. In modern Java/Spring, compare hand-written creation patterns with DI, constructors, static factories, and configuration.

## Senior focus
For every pattern, explain **intent, forces, a non-pattern alternative, one framework example, trade-offs, and a case where you would reject it**.
