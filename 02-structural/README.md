# Structural Patterns

Structural patterns arrange objects/types to create useful boundaries and composition. Prefer designs that keep dependency direction and runtime cost visible.

## Senior focus
For every pattern, explain **intent, forces, a non-pattern alternative, one framework example, trade-offs, and a case where you would reject it**.
