# Behavioral Patterns

Behavioral patterns organize collaboration, control flow, and responsibility. Senior use requires reasoning about ordering, errors, concurrency, lifecycle, and observability.

## Senior focus
For every pattern, explain **intent, forces, a non-pattern alternative, one framework example, trade-offs, and a case where you would reject it**.
